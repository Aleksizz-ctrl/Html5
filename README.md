## Description
Website with JavaScript tasks: variables, DOM manipulation,
events, calculator and an interactive To-Do list.

## Pages
- index.html: Task 0-1, first script, variables and operators (see console)
- dom.html: Task 2-4, changing text, styles, adding/removing list items
- events.html: Task 5-7, mouse events, keyboard events, calculator
- todo.html: Task 8, To-Do list

## How to run
1. Clone the repository
2. Open index.html in a browser
3. Use the navbar to switch between pages
4. Open the console (F12) to see the output of Task 0-1
